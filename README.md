# Azure Synapse Analytics (azure-synapse)
Azure Synapse Analytics is an enterprise analytics service that accelerates time to insight across data warehouses and big data systems. It brings together the best of SQL technologies, Spark technologies, Data Explorer, and integrated pipelines for data integration and ETL/ELT.

**URL:** [Visit APIs.json URL](https://azure.microsoft.com/en-us/services/synapse-analytics/)
